# ProjectSync

ProjectSync is the package button for the workbench project mirror sync script.

It wraps the root `sync.ps1`, which refreshes `Projects/<name>/baseline/` and the
per-agent edit copies from the configured source project repositories.

ProjectSync lives at `Packages/ProjectSync/`. It is a built-in one-way project mirror
that exposes a **`Sync`** command (not `Start`/`Finish`), so the folder-scanning root
`Start.ps1` / `Finish.ps1` intentionally skip it. Run it manually when the mirror
needs a refresh.

## Usage

Refresh all configured projects:

```powershell
.\Packages\ProjectSync\Sync.ps1
```

Refresh one project:

```powershell
.\Packages\ProjectSync\Sync.ps1 -Project CyphenEngine
```

Reset edit mirrors:

```powershell
.\Packages\ProjectSync\Sync.ps1 -ResetEdit All
```

Preview without writing:

```powershell
.\Packages\ProjectSync\Sync.ps1 -DryRun
```

First-time setup (create `Projects/projects.json` from the example):

```powershell
.\Packages\ProjectSync\Startup.ps1
```

Central taskbar shortcuts (`Project-Sync`, `Project-Startup`) are generated by the
workbench root `Launchers/Create-Shortcuts.ps1`.
