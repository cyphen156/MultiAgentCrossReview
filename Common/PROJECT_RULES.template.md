# <ProjectName> 프로젝트 규칙

사용자가 등록 프로젝트에 별도 규칙을 원할 때 이 파일을 `Projects/<name>/RULES.md`로 복사합니다. `Projects/<name>/`은 공개 Git에서 제외되므로 프로젝트 내부 규칙이 공개 템플릿에 섞이지 않습니다.

이 파일은 선택 사항입니다. 파일이 있으면 해당 프로젝트 작업에 반드시 적용하고, 없으면 공통 규칙만 사용합니다. `run-review.ps1`은 정식 검토 프롬프트에 공통 규칙과 활성 프로젝트 규칙을 함께 전달합니다.

아래 항목 중 프로젝트에 필요한 것만 남깁니다.
