# MultiAgentCrossReview 프로젝트 규칙 예시

이 파일은 WorkbenchStateVault가 운반하는 `Projects/<name>/RULES.md`의 공개 예시입니다.

## 공개 경계

- 공개 저장소에는 검토 절차, 템플릿과 실행 도구만 둡니다.
- 실제 검토 기록은 연결된 WorkbenchStateVault에 둡니다.
- 원문 대화 세션은 Workbench 상태와 분리해 AgentSessionVault가 다룹니다.

## 검토 기록

- 각 에이전트는 하나의 `REVIEW.md`를 갱신합니다.
- 사용자의 최종 결정은 하나의 `DECISION.md`에 남깁니다.
- 변경 이력은 상태 저장소의 Git 커밋으로 보존합니다.

## 공개 예시

- 개인 경로와 프로젝트 내부 정보가 남지 않도록 정리한 자료만 공개합니다.
- 공개 예시는 실제 `Reviews/<review-id>/`가 아니라 `Examples/` 아래에 둡니다.
